Dans le cadre de ma formation d’ingénieur, j’ai réalisé mon stage de fin d’études chez \textbf{Inetum Offshore Maroc} pour le projet de transformation numérique d’un \textbf{opérateur telecom}. L’objectif était de centraliser le patrimoine réseau et client dans la solution \textbf{Ni2 Unified Inventory}.

\medskip

La première partie de mon stage a concerné la migration du référentiel technique \textbf{GAIA} (Cuivre et Fibre). Mon rôle consistait à analyser les données sources et à développer des scripts SQL pour reconstruire précisément la topologie du réseau dans Ni2.

\medskip

La deuxième partie était dédiée à la migration du \textbf{CRM}. J’ai mené un travail de rétro-ingénierie sur une base de données complexe afin de réconcilier les données clients avec l'inventaire technique. J’ai également mis en place un pipeline de déploiement industriel via des scripts Shell pour automatiser et sécuriser l’importation des données.

\medskip

Ce stage m’a permis de maîtriser la migration de données massives, la rétro-ingénierie et le déploiement sur serveurs distants dans un contexte télécom.
