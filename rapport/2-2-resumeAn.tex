As part of my engineering training, I completed my graduation internship at Inetum Offshore Maroc for a telecom operator's digital transformation project. The objective was to centralize network and customer assets within the \textbf{Ni2 Unified Inventory} solution.
\medskip

The first part of my internship involved the migration of the \textbf{GAIA} technical repository (Copper and Fiber). My role consisted of analyzing source data and developing SQL scripts to accurately reconstruct the network topology in Ni2.

\medskip

The second part was dedicated to the \textbf{CRM} migration. I conducted reverse engineering on a complex database to reconcile customer data with the technical inventory. I also implemented an industrial deployment pipeline via Shell scripts to automate and secure data imports.

\medskip

This internship allowed me to master large-scale data migration, reverse engineering, and remote server deployment in a telecom context.
